# Agent notes

## Verifying visual/UI changes
When a change affects the generated HTML (discussion viewer, dashboard, index)
or any other visual output, **open the file for me to inspect visually** — e.g.
`open <path-to-output>.html`. Don't drive a browser yourself to test it; I'll
check the result. Still verify non-visual behavior (typecheck, data correctness,
markers/values in the generated output) as usual.
